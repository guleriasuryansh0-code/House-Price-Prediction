# House Price Prediction System using Decision Tree Regressor

A machine learning project that predicts residential real estate prices based on structural features, location, and neighborhood attributes using a Decision Tree Regressor with scikit-learn.

## Project Overview
This project implements an end-to-end regression pipeline to estimate housing prices. It preprocesses numerical housing attributes, trains a regularized Decision Tree Regressor, and evaluates prediction metrics ($R^2$, MSE).

## Repository Structure
- `project_2/main.py`: Core script for data loading, model training, and evaluation.
- `project_2/requirement.txt`: Required Python dependencies.
